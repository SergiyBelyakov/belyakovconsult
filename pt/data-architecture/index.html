Em que trabalhamos

O que inclui o trabalho

Olho para a arquitetura a partir de dois extremos. Como os sistemas funcionam hoje e como a liderança precisa de usar o resultado. O desenho alvo tem de ligar essas duas realidades.

  • Inventariar fontes, tabelas, integrações e fluxos de informação.
  • Definir modelos conceptuais, lógicos e analíticos.
  • Desenhar Data Warehouse, data marts e camada semântica para reporting.
  • Traçar data lineage desde os campos de origem até aos indicadores, relatórios e APIs.
  • Definir padrões de integração, master data, reference data e controlos de mudança.
O que recebe

O que recebe

  • mapa das fontes e fluxos atuais
  • arquitetura de dados alvo
  • modelos de entidades e relações
  • lineage para indicadores críticos
  • requisitos técnicos e plano de transição
