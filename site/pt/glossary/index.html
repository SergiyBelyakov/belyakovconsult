Glossário: dados, BI e análise em palavras simples

Definições curtas dos termos que uso nos artigos, da qualidade e governação de dados ao Power BI e ao Microsoft Fabric. Cada termo explica porque importa para o negócio e onde ler mais.

ABCDEFGIKLMOPQRST
AAnalytics engineerUma função entre engenheiro de dados e analista que transforma dados em modelos prontos para análise como código (SQL, dbt), com testes e versões em Git. AArquitetura de dadosA descrição de onde vêm os dados, onde e em que forma são guardados, como são transformados e como chegam aos relatórios e sistemas. AArquitetura medalhão (Bronze, Silver, Gold)Divisão dos dados em camadas por grau de preparação. Bronze são dados em bruto, Silver limpos e conciliados, Gold prontos para relatórios e análise. AAtualização incrementalUma configuração do Power BI em que só os períodos novos ou alterados são recarregados na atualização, mantendo o histórico. BBI (business intelligence)Processos e ferramentas que transformam os dados de uma empresa em relatórios, dashboards e indicadores para a tomada de decisão. CCapacidade Fabric (F SKU)Um conjunto dimensionado de computação do Microsoft Fabric onde correm as áreas de trabalho. A Microsoft já não vende novas capacidades Power BI Premium (P SKU); as F SKU substituem-nas. CCardinalidadeO número de valores distintos numa coluna. Identificadores, carimbos temporais ao segundo e texto livre têm cardinalidade elevada. CCompletudeA proporção de campos ou registos obrigatórios que estão preenchidos. Uma das dimensões da qualidade dos dados. DDashboardUm painel interativo que reúne indicadores-chave e gráficos para uma visão rápida da situação. DData lakeArmazenamento para grandes volumes de dados em bruto, em qualquer formato, normalmente em armazenamento de ficheiros económico na nuvem. DData stewardUma pessoa que cuida diariamente da qualidade dos dados da sua área, resolvendo erros, duplicados e registos em disputa segundo as regras do responsável pelos dados. DData warehouseUma base de dados separada onde os dados de diferentes sistemas são reunidos de forma agendada e conciliados para análise e reporte. DDAXData Analysis Expressions, a linguagem de fórmulas do Power BI e do Analysis Services para medidas e cálculos no modelo. DDirectQueryO modo do Power BI em que os dados não são copiados e cada interação no relatório envia uma consulta diretamente à fonte. DDirect LakeUm modo de modelos semânticos no Microsoft Fabric em que o motor do Power BI lê os dados diretamente de tabelas Delta no OneLake, sem importação separada. EELTExtract, Load, Transform. Os dados são carregados tal como estão no warehouse e transformados lá dentro, muitas vezes como código (por exemplo em dbt). EEngenheiro de dadosUm especialista que constrói e mantém integrações, pipelines de carga e armazenamentos de dados: ETL e ELT, orquestração, monitorização. EEsquema em estrelaUma forma de organizar dados para análise: uma tabela de factos ao centro, rodeada de tabelas de dimensões ligadas de um para muitos. EETLExtract, Transform, Load. Os dados são extraídos das fontes, transformados e só depois carregados no data warehouse. FFTE (equivalente a tempo inteiro)Uma unidade de carga de trabalho igual a uma pessoa a tempo inteiro. GGovernação de dadosAs regras, funções e processos que definem quem é responsável pelos dados, como são definidos, quem tem acesso e como se resolvem divergências. IInstantâneo de dados e data de corteUm estado dos dados guardado numa data concreta (a data de corte) que já não muda, mesmo que a fonte seja corrigida depois. IISO 8000Uma série de normas internacionais sobre qualidade de dados, incluindo a qualidade dos dados mestre e a troca de dados entre organizações. KKPI (indicador-chave de desempenho)Um indicador que uma empresa ou equipa usa para avaliar se está a atingir os seus objetivos. LLakehouseUma arquitetura que junta data lake e data warehouse: os dados ficam num formato aberto de tabelas (como Delta) e servem tanto a engenharia como os relatórios. MMedida (Power BI)Uma fórmula DAX que calcula um valor no momento da consulta, respeitando os filtros do relatório, como a receita ou a margem. MMicrosoft FabricA plataforma de análise da Microsoft que reúne engenharia de dados, data warehouse, lakehouse, Power BI e outras ferramentas em torno do armazenamento partilhado OneLake. MModelo compostoUm modelo semântico do Power BI em que algumas tabelas usam Import e outras DirectQuery. MModelo semânticoA camada entre os dados e os relatórios onde se definem tabelas, relações, medidas e regras de acesso. No Power BI chamava-se antes conjunto de dados (dataset). MModo ImportO modo do Power BI em que os dados são copiados para um modelo comprimido em memória e atualizados de forma agendada. OOneLakeO armazenamento de dados lógico único do Microsoft Fabric para toda a organização, onde as tabelas ficam no formato aberto Delta. PPBIP e TMDLO formato Power BI Project (PBIP) guarda o relatório e o modelo como ficheiros de texto; o TMDL é a linguagem de texto que descreve um modelo semântico. PPipeline de implementaçãoA funcionalidade do Power BI e do Fabric para mover conteúdo entre áreas de trabalho de desenvolvimento, teste e produção. PPower BIA plataforma de BI da Microsoft para modelação de dados, relatórios e dashboards, hoje parte do Microsoft Fabric. PPower QueryA ferramenta de preparação de dados do Power BI e do Excel, com a linguagem M: ligação às fontes, limpeza, junção de tabelas. QQualidade dos dadosAté que ponto os dados servem o seu propósito: completos, exatos, coerentes, atempados e sem duplicados. QQuery foldingA capacidade do Power Query de traduzir os passos de transformação numa consulta à fonte, para que filtros e junções corram lá e não no Power BI. RRegisto duplicadoVários registos num sistema que descrevem a mesma coisa, como uma pessoa ou um contrato. RResponsável pelos dados (data owner)Uma pessoa do negócio responsável pelas definições, pela qualidade e pelas regras de acesso aos dados da sua área. SSegurança ao nível da linha (RLS)Regras no modelo semântico que limitam as linhas de dados que um utilizador pode ver, por exemplo apenas a sua região. SSelf-service BIUma abordagem em que os utilizadores do negócio criam os seus próprios relatórios e análises, sem uma equipa de desenvolvimento para cada pedido. TTabela de dimensõesUma tabela que descreve por que eixos os factos são analisados: clientes, produtos, departamentos, datas. TTabela de factosUma tabela de eventos ou transações e dos seus valores numéricos: vendas, pagamentos, expedições. Cada linha é um evento.
