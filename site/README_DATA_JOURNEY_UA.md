# Шлях даних

Оновлено 22 жовтня 2026 року. Подорож показує, як підприємство рухається від джерел і бізнес-питання до перевірених показників, аналітики, користувачів та дій.

Українська версія: `/data-journey/`. Англійська: `/en/data-journey/`. У маршруті є вступ, 13 етапів, 9 напрямів роботи та 78 компонентів. Каталог пояснює роль, вхід і результат кожного компонента. Можна простежити один умовний запис, перевірку якості та повернення помилки на виправлення.

Головна ілюстрація має анімацію з паузою. Рух зупиняється поза екраном та при системному налаштуванні зменшення руху. Запрошення до маршруту розташоване після напрямів застосування.

Моделі розташовані в `data-journey/assets/glass/models/`, прев’ю в `data-journey/assets/glass/previews/`. Реєстр з актуальними розмірами й SHA256: `data-journey/assets/glass/catalog.json`. Джерельні генератори збережені в кореневій папці `dev-assets/`, яка не публікується.

Для локального перегляду запустіть `start_local.command`, `start_local.bat` або `bash start_local.sh` з цієї папки. Відкрийте `http://localhost:8000/`. Для 3D потрібен WebGL 2. Без нього пояснення й каталог залишаються доступними разом із прев’ю. Перевірки та їхні обмеження наведені у `data-journey/verification.json`.
