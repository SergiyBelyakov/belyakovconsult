# Belyakov Consult · WebGL 360° · Metal Glass Neon

Проєкт готовий для розгортання у папці `site/`. Усі українські й англійські сторінки збережено.

Оновлено `site/data-journey/models3d.js` та `neon-effects.js`: коригування PBR-матеріалів темного металу, прозорого скла й червоного неону; HDR-композиція з вибірковим червоним bloom та одноразовим tone mapping. 50 GLB-моделей залишено повноцінними геометричними 3D-об'єктами.

Новий `scene-orbit.js` забезпечує обертання **всієї сцени** на 360° по горизонталі, нахил камери, масштабування, анімаційне згладжування. Керування працює в усіх етапах маршруту, в системній мапі і в перегляді компонента.

**Керування**: ліва кнопка миші + перетягування = обертання, колесо = наблизити / віддалити, на сенсорному екрані один палець = обертання, два пальці = масштаб. Кнопки `−`, `+`, `Обертати`/`Rotate`, `↺` = масштаб, авторотація та скидання ракурсу. Фокус на полотні дозволяє клавіші стрілок, `+`, `−`, `0`.

В обох мовних версіях вилучено пряме посилання для завантаження GLB та код завантаження на вимогу. Заборонено перетягування картинок і контекстне меню на сцені та в каталозі. З `site/` прибрані вихідні Python-файли моделювання і референсний GLB, вони збережені для розробника в `dev-assets/data-journey/source/` **поза сайтом**.

**Обмеження захисту:** GLB, які візуалізуються клієнтським WebGL, браузер мусить отримувати як файли. Це означає, що технічно підготовлений відвідувач усе ще може отримати їх через Network/DevTools або витягти геометрію з GPU. Заборонити таке на звичайному статичному сайті неможливо. Для реального контролю доступу потрібен серверний рендеринг або авторизований захищений перегляд із компромісами щодо інтерактивності. Прев'ю також можуть бути збережені скриншотом.

**Результати перевірки:** валідність синтаксису скриптів перевірено Node.js, коректність структури 50 GLB-моделей і сценарій повного обертання / масштабування перевірено автоматично. Автоматичне візуальне тестування WebGL 2 у поточному середовищі недоступне. Для фінального контролю кольорів і bloom потрібно відкрити проєкт у Chrome/Safari із WebGL 2 та GPU.

**Публікація**: у папці архіву виконайте `bash deploy_main.sh`, щоб замінити `main` репозиторію `SergiyBelyakov/belyakovconsult_digital` вмістом `site/`, не змінюючи історію Git. Команда повністю видалить файли попередньої версії, яких немає у `site/`. Перед запуском переконайтесь, що саме цього хочете. Публікація домену залежить від конфігурації хостингу.
