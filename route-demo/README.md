# Демо планування логістичних маршрутів

Сторінка: `/cases/route-planning/` (UA) і `/en/cases/route-planning/` (EN). Збірка: `node route-demo/build.mjs`
(спільний `shared/build-demo.mjs`, запис `route-planning` у `shared/demos.json`).

Синтетичний регіон 150 на 100 км з річкою Ясна, 64 населеними пунктами і 101 ділянкою доріг. Регіональний
дистриб'ютор возить із двох складів 12 машинами замовлення до супермаркетів, магазинів, лікарень, шкіл і пунктів
незламності з вікнами приймання. Усе рахується в браузері.

## Файли

- `src/geo.js` геометрія: випадкові числа з зерном, сплайни, вигини доріг, перетини.
- `src/world.js` регіон: межі, річка, озеро, ліси, населені пункти (12 опорних + села з мінімальною відстанню),
  дороги (граф відносного сусідства на кожному березі, переправи, класи за коридорами між містами), автопарк,
  тарифи, клієнти й замовлення дня (`dayOrders(day)`).
- `src/graph.js` Дейкстра для кожного типу машини за умовами дня (закриті ребра, повінь, ожеледь, вагові обмеження),
  матриці між точками, шляхи по ребрах, центральність Брандеса, мости графа й точки зчленування.
- `src/solver.js` оптимізатор CVRPTW: savings для кожного складу з кількома стартами, вибір машин, вставка
  залишків, локальний пошук (відрізки 1-3, 2-opt, обмін хвостами, обмін зупинками, злиття, склад і тип машини),
  старт із попереднього плану; ручний план для порівняння (sweep за берегом), навантаження доріг, критичність ділянок.
- `src/state.js` стан демо (склади, автопарк, пальне, зміна, закриті дороги, день, правки замовлень, сценарії)
  і повний розрахунок.
- `src/engine.js` canvas-рушій: камера з нахилом і легкою перспективою, малювання, вантажівки на годиннику, ефекти,
  морфінг «кілометри → хвилини».
- `src/MapStage.jsx` карта-сцена з жестами: склад перетягується з магнітом, ніж закриває дороги, довге
  натискання відкриває кругову ручку замовлення, шкала дня, HUD, клавіатура.
- `src/controls.jsx` поворотна ручка з клацаннями (перерахунок після відпускання), одометр, чип зміни.
- `src/charts.jsx` розклад машин (Ґантт), структура вартості, смуги, доставки за годинами.
- `src/pages/` Диспетчерська, Мережа доріг, Сценарії (з перебором місць для третього складу), Замовлення і
  сигнали, Методика і дані.
- `src/sound.js` синтезовані клацання (типово вимкнені) і вібрація на телефоні.

## Перевірка в Node

```js
import { makeProblem, solve, manualPlan } from './src/solver.js';
```

Тестовий хук для Playwright: якщо до завантаження задати `window.__RP_TEST = {}`, сцена кладе туди свій стан
(`__RP_TEST.sc.hit` з екранними координатами вузлів і складів).
