# Демо-дашборд якості даних

Інтерактивний приклад аналітичної роботи для сайту: `/cases/data-quality-dashboard/` (UA), `/en/…`, `/pt/…`.
Вихідний код тут, зібрана версія лежить у `site/cases/data-quality-dashboard/` і публікується разом із сайтом.

## Що вміє

- **Шість сторінок:** Огляд, Аналітика, Якість даних, Джерела даних, Звіти, Вигляд. Адреса сторінки й фільтрів у хеші:
  `#quality&region=odesa&domain=health&period=6`, тож у дописах можна давати посилання одразу на потрібний сегмент.
- **Фільтри:** період 3/6/12 місяців, регіон, напрям, пошук. Клік по клітинці матриці, легенді чи смузі теж фільтрує.
- **Цільовий рівень якості** на повзунку (сторінка «Якість даних»): від нього залежать статуси всюди, зокрема в PDF.
- **PDF-звіт** (сторінка «Звіти»): векторний A4 у світлій темі бренду, Montserrat і Inter з кирилицею, обрані розділи,
  поточні фільтри, методика, номери сторінок. Формується у браузері (jsPDF), дані нікуди не надсилаються.
- **CSV:** експорт вибірки, імпорт власного файлу (колонки `month, region, domain, processed, valid, incidents, latency, availability`), зразок.
- **Заявка «Такий дашборд для вас»:** форма Formspree сайту (`xykwoaql`) з полями `source=dashboard-demo`, `cta` (де натиснули),
  `lang`, `page` і UTM-мітками з адреси. Заявки приходять туди ж, куди й із форми сайту.
- **Мови:** UA, EN, PT. Перемикач веде на ту саму сторінку іншою мовою зі збереженням фільтрів.

Дані синтетичні: 12 місяців × 6 регіонів × 5 напрямів = 360 записів, детерміновані. Кілька умовних аномалій закладено
навмисно (`ANOMALIES` у `src/data.js`), щоб на демо було що знаходити: провал якості Одеська × Охорона здоров’я в серпні 2026,
проблема доступності Харківська × Геопросторові дані в червні 2026 та інші.

## Збірка

```bash
cd dashboard
npm install          # react, react-dom, esbuild
npm run build        # → ../site/cases/data-quality-dashboard/ і сторінки /en/, /pt/
```

Шрифти для PDF (`public/pdf-fonts/`) уже згенеровані. Перегенерувати з `fonts/` репозиторію: `npm run fonts` (потрібен Python з fontTools).
jsPDF лежить у `vendor/` (версія 4.2.1, MIT) і підвантажується лише при натисканні «Завантажити PDF».

Перевірити локально: `python3 -m http.server -d site 8000` і відкрити `http://localhost:8000/cases/data-quality-dashboard/`.

## Структура

| Файл | Що в ньому |
| --- | --- |
| `src/data.js` | Довідники, генерація даних, розрахунки, статуси, CSV |
| `src/model.js` | Похідні показники для поточної вибірки |
| `src/i18n.js` | Тексти UA / EN / PT (без тире, як на сайті) |
| `src/charts.jsx` | Графіки на SVG: площина, стовпчики, кільце, смуги, малі множини, матриця |
| `src/pages/*.jsx` | Сторінки перемикача |
| `src/pdf.js` | PDF-звіт |
| `src/lead.jsx` | Форма заявки |
| `src/styles.css` | Стилі за дизайн-системою: matte glass, радіус ≤ 6px, Ruby лише як сигнал |
| `build.mjs` | Збірка і генерація сторінок з canonical, hreflang, Open Graph |

## Формули

- Опрацьовано записів = Σ processed
- Якість даних = Σ valid / Σ processed × 100%
- Доступність джерел = середнє availability; SLA 99,0%; затримка SLA 250 мс
- Інциденти = Σ incidents; частота на 100 тис. записів = інциденти / записи × 100 000
- Статус якості: «Норма» від цілі, «Увага» до 1 п. п. нижче, далі «Критично»
- Динаміка: перший і останній місяць вибраного періоду

## Палітра графіків

Серії напрямів у порядку дизайн-системи: Cobalt `#3B82F6`, Teal `#019586`, Violet `#A855F7`, Magenta `#EC4899`, Cyan `#07A4BA`
(Teal і Cyan трохи притемнені, щоб пройти перевірку контрасту й розрізнення). Amber пропущено, бо в дашборді він означає статус «Увага».
Ruby `#D90429` лише для виділеного елемента й останньої точки. Статуси: Emerald, Amber, Coral, завжди зі словом або іконкою.
